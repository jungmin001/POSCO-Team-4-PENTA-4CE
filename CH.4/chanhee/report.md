1. 분석 대상과 평가 기준

pdm-v2.2.0 데이터셋의 시나리오 분할을 유지하여 학습 216개, 검증 72개 시나리오를 사용하였다. 최종 D 작업이 완료되고 결함 정답을 확인할 수 있는 흐름만 분석에 포함하였다.
학습 대상은 5,920개 FLOW, 검증 대상은 1,978개 FLOW이며, 검증 자료에는 결함 308개와 정상 1,670개가 포함되어 있다. D 작업이 완료되지 않은 2,470개 FLOW는 정상으로 처리하지 않고 제외하였다. 테스트 자료는 사용하지 않았다.
성능은 AP, 정밀도, 재현율과 함께 발견한 결함·놓친 결함·오경보 수로 평가하였다. AP는 특정 경보 기준에서의 정확도가 아니라, 실제 결함에 높은 위험 점수를 부여하는 능력을 나타내는 지표이다.

2. 예측 시점 선정

먼저 검사값을 이용하여 E·C·B·A 검사 직후의 최종 결함 예측 성능을 비교하였다. 동일한 검증 FLOW를 사용하고, 경보 기준은 0.5로 고정하였다.
- E 직후: AP 0.454, 결함 93개 발견, 오경보 17개
- C 직후: AP 0.740, 결함 205개 발견, 오경보 22개
- B 직후: AP 0.842, 결함 243개 발견, 오경보 23개
- A 직후: AP 0.932, 결함 270개 발견, 오경보 10개
예측 시점이 뒤로 갈수록 성능은 높아졌지만, D 종료까지 남은 시간의 중앙값은 E·C·B·A 직후 각각 8·6·4·2시간으로 감소하였다.
C 검사 직후에는 E 직후보다 AP와 결함 발견 수가 크게 증가하면서도, D 종료까지 중앙값 기준 6시간이 남아 있었다. 따라서 예측 성능과 조기 확인 기회를 함께 고려하여 C 검사 직후를 기준 시점으로 선정하였다. 다만 6시간이 실제 조치에 충분한지는 별도로 검증하지 않았다.

3. 후속 설비의 과거 센서 추가

초기 모델은 F·E1·E2·C 공정의 QUALITY_INDICATOR만 사용하였다. 이 모델은 최종 결함 308개 중 205개를 발견했으나, 정답에서 B·A·D 설비가 원인으로 표시된 결함 103개는 모두 놓쳤다.
이를 개선하기 위해 C 검사 시점에 이미 관측된 B·A·D 설비의 과거 센서를 추가하였다. 예를 들어 C 검사가 12시에 완료되었다면, 최근 2시간 실험에서는 해당 설비의 10시부터 12시까지 기록을 사용하였다. 해당 FLOW가 이후 B·A·D 공정을 수행하면서 발생하는 미래 센서는 사용하지 않았다.
센서는 평균·표준편차·최근값 등으로 요약하였다. 경보 기준 0.5에서 전체 후속 설비의 과거 센서를 추가한 결과, AP는 0.740에서 0.863으로 증가하였고 발견 결함은 205개에서 228개로 증가하였다. 오경보는 22개에서 49개로 증가하였다.
원인별 분석에서는 기존에 놓쳤던 B·A·D 원인 결함 중 49개를 새로 발견하였다. 반면 기존에 발견했던 F·E·C 원인 결함 26개를 새로 놓쳐, 전체 발견 결함의 순증가는 23개였다.
이는 후속 공정에 진입하기 전에도 해당 설비의 과거 상태가 최종 결함 예측에 도움이 될 수 있음을 보여준다. 다만 원인 설비 정답은 사후 오류 분석에만 사용하였으며, 모델 입력에는 포함하지 않았다.

4. 시간창·모델·센서 특징 비교

후속 설비의 과거 센서 범위를 최근 1·2·4시간으로 변경하고, B 설비만 사용하는 경우와 B·A·D 전체를 사용하는 경우를 비교하였다. 전체 센서를 사용하는 모델은 B 설비만 사용하는 모델보다 A·D 원인 결함까지 탐지하는 데 유리한 결과를 보였다.
이후 모델을 변경하고 센서 특징을 확장하였다. 최근 1시간의 센서 요약값에 최근 1·4시간의 추세와 최근 4시간 평균을 추가하여, 현재 수준뿐 아니라 시간에 따른 변화도 반영하였다.
전체 센서를 사용한 랜덤 포레스트의 검증 AP는 약 0.918이었으며, 추세 특징을 포함한 히스토그램 그래디언트 부스팅은 약 0.964를 기록하였다. 모델과 입력 특징이 함께 변경되었으므로, 이 차이 전체를 알고리즘 교체만의 효과로 해석하지는 않았다.

5. 경보 기준 선정과 최종 검증 결과

최종 후보는 학습 자료 내부 평가에서 재현율 95%를 목표로 경보 기준을 선택하였다. 선정된 기준은 약 0.1311이며, 이 기준을 검증 자료에 그대로 적용하였다.
최종 검증 결과는 다음과 같다.
- AP: 0.9635
- 정밀도: 75.7%
- 재현율: 97.1%
- 실제 결함 308개 중 발견: 299개
- 놓친 결함: 9개
- 오경보: 96개
동일한 최종 모델에서 경보 기준을 0.5로 적용하면 결함 269개를 발견하고 오경보 30개가 발생하였다. 기준을 약 0.1311로 낮추면서 결함 30개를 추가로 발견한 대신, 오경보는 66개 증가하였다.
따라서 현재 기준은 결함 누락을 줄이는 데 중점을 둔 설정이다. 실제 운영에 적용할 때에는 추가 검사 부담과 결함 누락의 영향을 함께 고려해야 한다.

6. 놓친 결함과 오경보 사례 분석

최종 모델이 놓친 결함 9개는 A 원인 3개, C 원인 2개, D 원인 2개, B 원인 1개, E1 원인 1개였다.
사례 분석에서는 C 시점에 이상 신호가 약하게 나타났다가 실제 후속 작업 중 변화가 커진 경우, 이후 부하·운전 조건이 달라진 경우, 검사값이 품질 판정 경계 부근에 위치한 경우 등이 확인되었다. 이는 누락 원인에 대한 분석 근거이며, 각 사례의 정확한 예측 실패 원인을 확정한 것은 아니다.
오경보는 ‘결함 검사 요망’으로 예측했으나 실제 최종 D 결과는 정상이었던 경우이다. 일부 사례에서는 예측 이후 후속 작업 전에 정비가 수행되었다. 또한 이상 징후가 최종 결함으로 이어지지 않거나, 최종 품질이 정상 범위에 머무른 사례도 확인되었다. 다만 정비가 결함을 방지했다고 단정할 수는 없다.
이러한 결과를 고려하여 모델 출력은 **‘불량 확정’이 아닌 ‘결함 검사 요망’**으로 해석하였다.

7. 추가 개선 실험과 채택 여부

사례 분석을 바탕으로 두 가지 개선을 추가로 실험하였다. 첫째는 정비·정지 전후를 섞지 않고 재가동 이후 구간에서 센서 추세를 계산하는 방식이며, 둘째는 해당 FLOW에서 이미 완료된 E1·C 작업의 센서 특징을 추가하는 방식이다.
두 가지를 모두 적용한 모델은 AP 0.9604, 발견 결함 300개, 오경보 104개를 기록하였다. 기존 모델보다 결함을 1개 더 발견했지만 오경보가 8개 증가하였고, AP는 소폭 낮아졌다. 학습 자료 내부 비교에서도 기존 모델이 가장 높은 평균 AP를 보였다.
따라서 추가 방식은 최종 모델에 채택하지 않았다. 한편 실험 과정에서 D 원자료의 정지 상태가 전처리된 IS_STOPPED에 반영되지 않은 문제를 확인하였다. 해당 실험에서는 원자료의 RUNNING으로 정지 여부를 확인했으며, 전처리 문제는 별도 점검 사항으로 남겼다.

8. 현재 진행 상태와 한계

최종 후보 모델을 파일로 추출하였으며, 학습된 결측값 처리 과정·145개 입력 특징의 순서·경보 기준을 함께 저장하였다. 저장한 파일을 다시 불러왔을 때 기존 예측값이 동일하게 재현되는 것을 확인하였다.
현재 결과는 D 작업이 완료된 FLOW에 대한 검증 결과이다. 모델 및 특징 선택 과정에서 검증 자료를 반복 확인했으므로, 별도 테스트 평가 전까지 최종 일반화 성능으로 단정하지 않는다. 또한 위험 점수는 실제 결함 발생 확률로 보정·검증된 값이 아니다.
로지스틱 회귀, 랜덤 포레스트, 엑스트라 트리, 히스토그램 그래디언트 부스팅을 사용한 결과, 비교한 후보 중 히스토그램 그래디언트 부스팅이 우수한 결과를 내어 최종 선택했다. 히스토그램 그래디언트 부스팅은 여러 개의 의사결정나무를 순차적으로 학습하여 예측 성능을 높이는 모델이다. 여러 공정으로 이루어진 복잡한 관계성을 가진 데이터셋에서 검사값과 센서 특징 간의 관계를 반영하는 데 적합하였으며, 실험에서도 유리한 결과를 확인하였다.
